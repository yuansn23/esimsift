## eSIM 矩阵图片批量去水印 + 无损压缩（图片_backup_20260929）

- 需求：去除 132 张豆包 AI 生成图右下角"豆包AI生成"水印（裁剪方式），无损压缩后覆盖原图。
- 方案：Pillow 本地批处理。裁掉底部 130px（2848×1600 → 2848×1470，水印文字顶部最高约 y≈1500，留 30px 余量），PNG `optimize=True` 无损压缩，`os.replace` 覆盖原文件。
- 结果：132/132 成功，749.9MB → 666.2MB（省 11.2%）。抽查右下角确认无水印残留。
- 踩坑记录：
  1. 本环境 PowerShell 工具 stdout 被吞、Bash shim 损坏（PATH 缺 dirname/ls）——python 脚本一律把输出写文件再 Read。
  2. 批处理脚本 bug：`os.replace(tmp, path)` 之后又 `getsize(tmp)`，tmp 已被移走必抛 FileNotFoundError，导致日志误报全部失败（实际全部成功）。正确做法是 replace 前先取 tmp 大小，或 replace 后 getsize(path)。
  3. 调试时对已覆盖文件 `eSIM旅行功能图生成需求.png` 误多裁了一次 130px（现为 2848×1340），磁盘无原始副本，无法恢复，已向用户说明。
