Before you buy

One {{ .Params.region }} plan or several single country plans

The {{ .Params.region }} table compares single-country plans, because that is what the country pages show and what can be verified line by line. Regional and multi-country eSIMs exist and can be cheaper when a trip crosses several borders — but their prices are not listed the same way, so they never enter the league table above. The rule of thumb: for one country, buy that country's cheapest single-country plan; for three or more countries, check whether a regional plan beats the sum of its single-country parts.

One destination

Buy the single-country plan that tops the {{ .Params.region }} table for that country. The cheapest provider there is visible in the country page's own league table.

Several destinations

Sum the cheapest single-country plans for your {{ .Params.region }} route first, then compare that total against any regional plan before committing.
